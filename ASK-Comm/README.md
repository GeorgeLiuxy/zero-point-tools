# ASK 音频通信实验

该工具使用振幅键控（ASK）把文本编码为音频波形，再通过麦克风录音和阈值判决恢复比特及文本，用于演示最基础的数字调制、信道传输与解调过程。

## 文件

- `send.py`：把脚本中设置的消息编码并生成 `output.wav`，同时绘制波形。
- `receive.py`：从默认麦克风录制约 5 秒音频，按振幅阈值解调并尝试还原文本。
- `output.wav`：仓库内的示例调制音频。

## 安装与运行

```bash
cd ASK-Comm
pip install -r requirements.txt
python send.py
python receive.py
```

先用扬声器播放 `output.wav`，再启动接收脚本录音，或根据实验需要改写为直接读取 WAV。默认参数包括 44.1 kHz 采样率、约 1 kHz 载波和固定符号时长，均可在脚本中调整。

## 注意事项

- 接收端采用简单幅度阈值，环境噪声、音量、设备增益和时钟偏差都会明显影响结果。
- `sounddevice` 需要系统存在可用的录音设备及相应驱动。
- 该实现用于教学实验，不包含同步、纠错、校验或可靠通信协议。
