# 红外—可见光 Diffusion-GAN 图像融合

本目录包含多个逐步演进的 PyTorch 图像融合实验，将红外图像的目标显著性与可见光图像的纹理信息进行融合。部分版本引入时间步嵌入、正向加噪、对抗损失、L1 重建损失和梯度约束。

## 入口与版本

| 文件 | 说明 |
| --- | --- |
| `main.py` | 基础训练/推理实验入口 |
| `merge.py`、`merge_v2.py` | 早期融合版本 |
| `merge_linux_cuda*.py` | 面向 Linux/CUDA 的迭代版本 |
| `merge_linux_cuda_v3.py` | 包含扩散时间嵌入和正向加噪的较完整版本 |
| `generator*.pth`、`discriminator*.pth` | 已保存的模型权重 |
| `ir/`、`vis/` | 红外图与可见光图示例目录 |

## 安装与运行

```bash
cd AI/diffusionGan
pip install -r requirements.txt
python merge_linux_cuda_v3.py
```

不同脚本使用的路径和训练参数并不统一。运行前请检查脚本中的红外/可见光目录、输出目录、设备、批大小和权重路径；没有 CUDA 时需把设备配置改为 CPU。

## 数据要求

- 红外图像和可见光图像应按文件名一一对应。
- 两类图像需要具备相同或可对齐的空间尺寸。
- 输入归一化方式应与所加载权重的训练设置保持一致。

## 输出

训练过程会生成损失曲线、融合结果以及生成器/判别器权重。实际文件名由所运行的版本决定。

## 注意事项

该目录保留了多个实验分支，适合做算法对比，不是统一封装的生产接口。建议将确认可用的版本固定为单一入口后，再补充配置文件、验证指标和可复现实验参数。
