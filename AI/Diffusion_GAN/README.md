# Diffusion-GAN 图像融合早期原型

该目录保存红外图像与可见光图像融合的早期网络设计，包含生成器、判别器、损失函数和训练框架。目标是结合扩散思想与对抗训练，生成同时保留热目标和纹理细节的融合图像。

## 文件说明

- `generator.py`：融合生成网络。
- `discriminator.py`：对抗判别网络。
- `loss.py`：重建和对抗相关损失。
- `train.py`：训练流程草稿。
- `main.py`：预留入口，目前为空。
